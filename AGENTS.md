## Conventions

- Python 3.12+ with `src/` layout (`src/aictx/`).
- Use `from __future__ import annotations` in every module.
- Pydantic v2 for all data models.
- Direct `git` subprocess calls for important Git operations.
- All safety checks fail closed: report `unknown` or `needs-source` rather than guess.

## Architecture

- `src/aictx/cli.py` — Typer CLI entry point.
- `src/aictx/scan/` — Repository scanning, classification, secret detection.
- `src/aictx/llm/` — Model provider interface (`dry_run`, `oci_genai`).
- `src/aictx/context/` — Context planning, fact extraction, scaffold writer, lockfile.
- `src/aictx/verify/` — Strict verifier, hash checks, impact mapping.
- `src/aictx/public_docs/` — Public docs mapper and updater.
- `src/aictx/oci/` — OCI configuration, Object Storage, remote jobs.
- `src/aictx/io/` — File I/O, patches, JSONL helpers.

See `docs/AIprojectcontext/architecture.md` for detailed design.

## Rules for all agents

1. Read `docs/AIprojectcontext/ai-index.md` first to understand the project structure and which context shard to read next.
2. Do **not** read large human-facing public docs for general project context. Use the compact AI context files instead.
3. Public docs may be read only when the task is explicitly documentation-related, or when `aictx verify --strict` reports a public-docs impact.
4. Run `aictx verify --strict` before any public commit to ensure AI context is fresh.
5. If context is stale, run:
   ```bash
   aictx run --project . --mode setup-context --scope changed --write apply
   ```
6. If public docs are impacted, run:
   ```bash
   aictx public-docs update --project . --scope changed --write patch
   ```
7. Do not fabricate facts. If information is unavailable, mark it `unknown` or `needs-source`.
8. Preserve source references for all important claims.
9. Before calling the work finished you have to verify 0 errors in IDE problems output.
## Accuracy rules

- Source-trace all critical claims.
- No unsupported assumptions.
- Mark uncertainty explicitly.
- Fail closed: report `unknown` rather than guess.
